# A4 主动触发知识沉淀

## 上下文

知识沉淀如果依赖用户提醒，必然滞后或遗漏。

## 问题

- AI 默认“用户说总结才总结”。
- 高价值洞见出现后未及时入库。
- 现有条目冲突或过时无人处理。

## 方案

出现以下任一情况，AI 必须主动提议或直接输出更新：

| 触发条件 | 动作 |
| :--- | :--- |
| 新分层、新概念、新命名规范 | 提议更新文档结构 |
| 用户明确认可或批评某次协作 | 转为约定或反模式 |
| 复杂任务结束形成可复用流程 | 新增工作流或技能 |
| 现有技能被证明混淆/过时/冲突 | 标记废弃、合并或重写 |
| 每次更新 | 写 evolution-log |

动作标准：至少给增量；用户同意后给完整版；回答开头声明触发。

## 反面

- 不要等用户说“总结成 Skill”才行动。
- 不要只提议不落地。
- 不要静默修改文档。
