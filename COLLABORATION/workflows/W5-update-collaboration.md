# W5 更新 COLLABORATION

## 上下文

协作规范需要持续演化，否则会腐烂。

## 问题

- 新洞见无处安放。
- 旧条目冲突或过时。
- 结构僵化，无法生长。

## 方案

1. **识别触发条件**（见 A4）。
2. **分类**到约定 / 工作流 / 技能 / 领域 / 模式。
3. **输出增量或完整版**。
4. **更新 evolution-log**。
5. **询问用户确认**（约定必确认，技能可先斩后奏）。
6. **确认后作为新基线**。

## 反面

- 不要静默修改。
- 不要跳过 evolution-log。
- 不要在未分类前就写入。
