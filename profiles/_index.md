# Profiles 索引

每位协作者在此目录下维护 `<username>.yaml`，声明侧重点与排除项。

## 使用

- 复制 `_template.yaml` 为 `<你的用户名>.yaml`。
- 填写 `identity` / `focus` / `exclude` / `fork-policy`。
- AI 回答会读取此文件。（`collab sync` **尚未实现** —— 见 [[S10-collab-cli]]）

## 规则

- Profile 是偏好声明，不覆盖约定。
- 与 Git 身份冲突时，以 Git 为准。
- 不写敏感信息。
