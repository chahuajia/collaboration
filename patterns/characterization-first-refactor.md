# 行为冻结重构：把被替换的实现抄成预言机

## 上下文

重构的前提是"外部行为不变"。但**行为不变的证据从哪来**？
在没有测试的旧代码里（覆盖率低、某个屏幕上千行零测试），
"我读懂了这段逻辑"是最不可靠的证据来源 —— 而它恰好是模型最自信的部分。

## 问题

- 只断言"好看的数字"的测试**证明不了等价性**：它只证明了新实现在这几个用例上符合我的直觉。
- 先搬代码再补测试，会让两类变更混在一起：**重构引入的回归** 与 **顺手"修正"的旧规则**，事后无法区分。
- 旧代码里的"怪癖"（百分比券不支持固定额、税基含配送费、每步 `toFixed(2)`）
  在复述时会被**自动合理化**掉，于是重构悄悄变成了行为变更。

## 方案

1. **第一步先抄，不先改**：把要被替换的那段实现**原文**复制进测试文件，起名 `legacy*`，
   注释写明来源文件与行号。
2. **用例表覆盖输入空间**：典型值 + 边界 + 让舍入路径分叉的脏值
   （实测用过 `3.333×3`、`1.005` 配送费、`"0"` 小费、`null` 价格）。
3. **逐字段比对旧实现的输出**，而不是比对"我认为对的数"；
   比字符串（`toFixed(2)`）而不是比浮点数 —— 字符串才是用户看到的东西。
4. **怪癖写进测试注释并保留**：改怪癖是业务决策，必须先改预言机，
   于是"改行为"这件事在 diff 里**看得见**。
5. 旧实现删掉后，预言机留在测试里作为**回归锚点**；它同时是那段规则的规格文档。
6. **等价性声明要分级、可测量**（2026-10-06 补）：明说属于哪一档 ——
   **逐位相等** / **容差相等（给数字）** / **仅记录分歧**，禁止笼统的"行为不变"。
   实测例：同一段距离公式的两个调用方，"钱路"要求**逐位相等**
   （下游有 `Math.ceil`，末位差会放大成一个货币单位），"排序路"只要求**微米级相等**（1e-9 km），
   且差值要**量出来**而不是假设为零。

## 判据

- **能说出等价性覆盖了哪些输入**：说不出来，说明用例表是凑的。
- **脏值必须进用例表**：只测整数和整分，等价性结论是假的。
- **预言机必须与被替换实现逐字一致**：被"优化"过的预言机不叫预言机。
- **行为变更必须表现为预言机的 diff**：规则改了而预言机没动，这次重构是失控的。
- **等价性是分级的、可测量的**：给不出档位和数字，就不是结论。

## 反面

- 不要用"新实现 vs 新实现"的参数化测试冒充等价性 —— 那是自证。
- 不要为了通过等价性测试去迁就旧实现的 bug 而不记录：记录后保留，或明确改预言机，**不要静默两可**。
- 不要把预言机当长期规格：规则演进后，应改写为"期望值"测试并让预言机退场。
- 不要在无测试的重灾区（UI 屏幕、React context）跳过这一步直接搬代码 —— 那里恰恰最需要预言机。
