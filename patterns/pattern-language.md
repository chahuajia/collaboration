# 模式语言

## 上下文

需要描述“在什么情况下用什么方案”，而不是孤立的做法。

## 问题

只写“怎么做”，读者不知道适用范围和反面案例。

## 方案

每个条目采用五段式：
1. 上下文
2. 问题
3. 方案
4. 反面
5. 关联

## 反面

- 不要省略反面。
- 不要把上下文写成定义。
