# 知识的生态循环
## 上下文
多个知识实体并存时，需要理解它们的关系。
## 问题
- 直觉模型："水的三态"（气、水、冰）——**错误**，因为三态互斥。
- 直觉模型："线性流程"（甲→乙→丙）——**不够**，因为三者同时存在。
- 真实关系："生态循环"——各态并存、互为输入。
## 方案
### 生态循环模型
| 生态 | 知识 | 特征 |
| :--- | :--- | :--- |
| **草** | 原始对话 | 无结构、瞬时 |
| **兔（吃草）** | working-memory | AI 聚合当前任务状态 |
| **狐（吃兔）** | 知识笔记 | 人类可读的洞见 |
| **分解者** | COLLABORATION | 稳定化、结构化 |
| **土壤** | 归档 | 历史沉淀 |
| **新草** | 新对话 | 基于规范生长 |
### 关键差异（vs 水三态）
| 水三态 | 生态循环 |
| :--- | :--- |
| 互斥——不能同时存在 | **并存——互相喂养** |
| 相变是单向的（加热/冷却） | 流动是多向的（读、写、引用） |
| 同源但不同时 | **同源且同时** |
### 应用原则
- **各层同时存在**——不要"完成底层再做上层"。
- **互为输入**——working-memory 的内容可以喂给知识笔记；知识笔记可以喂给 COLLABORATION；COLLABORATION 反过来指导新对话。
- **分解者最稳定**——COLLABORATION 是所有循环的"回归点"。
- **土壤是历史**——归档不是垃圾，是"养分储备"。
## 反面
- 不要用"水三态"思维——那会让每层变成"独占状态"。
- 不要"完成一层再做下一层"——它们同时进行。
- 不要把归档当垃圾——它是未来洞见的矿藏。
