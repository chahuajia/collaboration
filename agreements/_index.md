## 索引

**本层定义**（2026-09-16）：**约定 = 协作规则** —— 只放"人和 AI 怎么一起工作"里
**不可谈判、且能被自查**的规则。

按这条定义，下面几类**不属于本层**，各有自己的家：

| 内容 | 归哪 |
| :--- | :--- |
| 思维方式（设计三问、跨域借鉴、三层反思） | `patterns/` 或 `workflows/` |
| 特定环境下的操作手册（对话式交互、输出格式、agent 写权限边界） | `integrations/` |
| 编码规范（值语义、类型技巧） | 真实项目的 `AGENTS.md` / 团队规约 |
| 术语表（方位词规范） | `meta/` |
| 执行流程（递归分析） | `workflows/` |
| 可表演、无约束力的仪式（声明模式、给鼓励） | **删除** |

**门槛**：新增一条约定，必须能回答"不看它，一个称职的通用模型会做错吗"。
答不上来就别加 —— 每加一条，都是向未来每一次交互收税。

> **编号缺口是刻意的**：本目录曾有过 `A1 A2 A5 A7 A8 A9 A11 A15 A17 A18 A19`，
> 它们已删除、并入或迁出。**id 是不可变快照，永不重编号**（见 [[ADR-0009-id-是不可变快照]]）——
> 缺口就是死亡记录，补齐它等于抹掉"这里曾经死过一条"。

## 变更规则

约定是承重墙，任何修改必须双方确认，并写 ADR 到 `meta/decision-records/`。
