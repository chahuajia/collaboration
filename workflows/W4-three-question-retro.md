# W4 复盘三问

## 上下文

复杂任务结束后，如果不复盘，经验会流失。

## 问题

- 做了什么没记录。
- 哪些有效哪些无效不清楚。
- 下次还会踩同样的坑。

## 方案

复杂任务结束，回答以下三问：

| 问题 | 更新对象 |
| :--- | :--- |
| 哪个技能最有效？ | 强化或新增技能 |
| 工作流哪一步卡住了？ | 调整顺序或检查点 |
| 约定是否需要补充？ | 双方确认后更新约定 |

必须输出**行动项**，否则不算完成。这是 OODA 闭环的“决策-行动”两步。

## 反面

- 不要只反思不行动。
- 不要把简单任务也强行复盘。
