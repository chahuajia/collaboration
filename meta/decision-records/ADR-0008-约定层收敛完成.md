# ADR-0008 约定层收敛完成：19 → 8

## 背景

[[ADR-0006-约定层收窄为协作规则]] 定了"约定 = 协作规则"，
[[ADR-0007-建立集成层]] 把环境适配分了出去。本 ADR 收掉剩下的一次性处置。

## 决策

| 条目 | 处置 | 依据 |
| :--- | :--- | :--- |
| `A1-output-format` | **并入 `skills/S1-h2-output`** | 与 S1 逐字重复（同一件事两条） |
| `A11-值同不代表语义同` | **降级为 `patterns/value-semantics`** | 约束"代码怎么写"，不是"怎么协作"；但它是**通用判据**，不绑语言/栈，所以留库 |
| `A18-内外有别` | **迁入 `meta/terminology`** | 术语表是查阅材料，不是行为约束 |
| `A19-递归式分析原则` | **迁入 `workflows/W11-递归式分析`** | 执行剧本 + **删除配额棘轮**（"至少 20 轮 / 2 轮 / 3 个 / 1 个"） |
| `A3-mutual-critique` | **改写**：删"鼓励" | 不可自证，只会训练迎合 |
| `A4-proactive-update` | **改写**：触发收窄为三条可观测事件；删"回答开头声明触发" | "复杂任务"没有判据 → 每次回答尾部追加元讨论（79KB bundle 的成因） |
| `A13-AI-入口文件规范` | **拆分**：外部知识库"怎么读"移出，指向 `integrations/` | "在哪"跨环境不变，"怎么读"是环境适配 |
| `A14-多实体协作原则` | **改写**：删"实体 vs 演化体"哲学段 | 不改变任何一方的行为 |

## 后果

**`agreements/` = 8 条**：`A3` `A4` `A6` `A10` `A12` `A13` `A14` `A16`。

- 从 19 条（五天写完）收到 8 条，每一条都通过四问：
  **是协作规则吗 / 能自查吗 / 前提准确吗 / 与已有条目重复吗**。
- 搬走了 11 条：3 条并入已有条目、4 条换层（skills / patterns / meta / workflows）、
  3 条进 `integrations/`、1 条删除。

负面：

- 旧编号 `A1` `A2` `A5` `A7` `A8` `A9` `A11` `A15` `A17` `A18` `A19` 全部成为历史名词。
  **只能靠 `git log` 找回** —— `aliases` 不被解析器使用，靠不住。
- 这一轮**没有迁移脚本**（基座变更应有），全靠 `collab validate` 兜底。
  下一次动基座（目录/frontmatter/id 语法）必须先写脚本。

## 替代方案

- **只降级不合并** —— 否决：`A1` 与 `S1`、`A2` 与 `W2` 这类是逐字重复，留着就是两份真相源。
- **一次收到 10 条就停** —— 否决：10 是拍脑袋的数字。按四问筛下来就是 8 条，
  多留 2 条只是为了让数字好看 —— 那是**为了指标而保留**。
- **把 `A11` 一起删掉** —— 否决：它不绑语言、不绑栈，是通用判据（"跨域共享同一个零会摧毁语义系统"），
  删了就丢了一个模型未必知道的洞见。
