# ADR-0006 约定层收窄为协作规则

## 背景

`agreements/` 五天内长到 19 条。但按内容看，它同时装着六种不同的东西：

| 类别 | 例子 | 规模律 |
| :--- | :--- | :--- |
| **协作规则** | A6 权限、A10 review 前置、A13 入口 | 稀缺 —— 每加一条收一次税 |
| 思维方式 | A2 三层反思、A8 设计三问、A9 跨域借鉴 | 累积 —— 越多越好 |
| 环境适配 | A15 对话式交互、A17 输出格式 | 随环境作废 |
| 编码规范 | A11 值语义 | 绑栈 |
| 术语表 | A18 方位词 | 查阅型 |
| 流程 | A19 递归分析 | 执行剧本 |

**协议按手册的速度增长**，于是宪法被稀释成备忘录。

## 决策

**`agreements/` 的定义收窄为：人和 AI 怎么一起工作里，不可谈判且能自查的规则。**

不满足这条的，各有自己的家：

| 内容 | 归哪 |
| :--- | :--- |
| 思维方式 / 通用判据 | `patterns/` |
| 执行流程 / 分析剧本 | `workflows/` |
| 特定环境的操作手册 | `integrations/<env>/` |
| 编码规范 | 真实项目的 `AGENTS.md` |
| 术语表 | `meta/` |
| 可表演、无约束力的仪式 | **删除** |

**新增门槛**：必须能回答"不看它，一个称职的通用模型会做错吗"。答不上来 → 不加。

### 第一批执行（19 → 15）

| 条目 | 处置 | 依据 |
| :--- | :--- | :--- |
| `A2-depth-and-reflection` | 并入 `W2-three-stage-analysis` | 与 W2 逐字重复（三段式） |
| `A5-declare-mode` | **删除** | 可表演、零约束力；五份评估一致点名 |
| `A8-设计不是可选项，只有好坏之分` | 并入 `patterns/design-decision` | 逐字重复（该 pattern 自己写着"源自 A8"） |
| `A9-跨域借鉴：不局限在代码思维` | 并入 `patterns/cross-domain-borrowing` | 逐字重复（该 pattern 写着 `source: A9`）；用户拍板降级 |

## 后果

正面：条目 106 → 102；约定 19 → 15；一个概念只有一处定义。
`agreements/_index.md` 写明了本层定义，"该类内容该放哪"有了判据。

负面：旧编号 `A2/A8/A9` 成为历史名词（`A5` 无替代物）。
**只能靠 `git log` 找回**，不再有 `aliases` 兜底 —— 因为 `aliases` 不被解析器使用。

## 替代方案

- **只删不并** —— 否决：三处是逐字重复，独有内容（触发条件、可落地判据）不该丢。
- **一次收完 19 → 10** —— 否决：剩下 4 条的处置有争议（A7 拆不拆、A11 降不降、
  A18/A19 搬不搬），需要用户逐条确认，不适合混在同一批里。
